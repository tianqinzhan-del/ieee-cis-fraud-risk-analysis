# IEEE-CIS 支付交易欺诈风险分析

## 1. 项目背景

本数据集包含 **590,540** 笔支付交易、**20,663** 笔欺诈交易，
整体欺诈率 **3.50%**。正负样本极不均衡，
因此后续评估不使用准确率，而使用命中率（precision）、召回率（recall）
和每日送审量这三个更贴近业务决策的指标。

分析目标：在每天固定人工审核名额的约束下，
比较不同排序与分档策略，给出可解释、可上线的规则配置建议。

## 12. 结论

1. **数据高度不平衡**：整体欺诈率仅 3.50%，
   因此业务上更关心“每天有限名额能抓到多少欺诈”，而不是整体准确率。
2. **单条金额规则的有效性有限**：阈值 500 时命中率 4.41%，
   仅略高于整体欺诈率 3.50%，召回率 4.88%，
   说明金额本身不足以区分欺诈，需要与群体特征组合。
3. **“产品 C + 信用卡”是最显著的风险群体**：
   欺诈率 16.92%，提升 4.84 倍，
   贡献 22.57% 的欺诈交易。
4. **按风险分排序优于按金额排序**：
   在测试期每天 100 个名额下，召回率由 5.76%
   提升到 21.63%。
5. **策略效果在观察窗口内波动但未持续恶化**：
   7 天分段的命中率在 15.71%–26.14% 之间，
   召回率在 17.13%–24.56% 之间。
   可作为规则上线前的基线方案，后续再用监督模型替换查表打分。
